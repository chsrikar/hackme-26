# HackMe'26 — Department of Computer Science & Engineering

The official website for **HackMe'26**, a 24-hour hackathon organized by Cyborgs, CSE Technical Association at VISAT Engineering College.

Built with **React**, **Vite**, **React Router DOM**, and custom CSS with a retro-futuristic pixel-art theme.

---

## Event Details

- **Date**: September 25-26, 2026
- **Venue**: VISAT Engineering College, Ernakulam, Kerala
- **Duration**: 24 hours
- **Prize Pool**: ₹1,45,000+
- **Registration Fee**: ₹50 per person

---

## Features

- 🎨 Retro-futuristic pixel-art design with glassmorphism effects
- 🎯 Multiple hackathon tracks (AI/ML, Web Dev, IoT, Open Innovation)
- 🏆 Comprehensive prize structure with track-specific awards
- 📅 Interactive schedule and timeline
- 👥 Team member showcase
- 🔒 Coming Soon page for unreleased content
- 📱 Fully responsive design
- ⚡ Fast and optimized with Vite

---

## Tech Stack

- **Frontend Framework**: React 19
- **Build Tool**: Vite 8
- **Routing**: React Router DOM
- **Styling**: Custom CSS with design tokens
- **Animations**: Anime.js
- **Icons**: Lucide React
- **Deployment**: Vercel

## Quick Start

### Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Open http://localhost:5173
```

### Production Build

```bash
# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

### Deploy to Vercel

#### Option 1: One-Click Deploy

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/yourusername/hackme26)

#### Option 2: Vercel CLI

```bash
# Install Vercel CLI
npm install -g vercel

# Deploy
vercel

# Deploy to production
vercel --prod
```

See [DEPLOYMENT.md](./DEPLOYMENT.md) for detailed deployment instructions.
